Frequently Asked Questions

            

                
What is an AI Agent Payment Boundary?

                
A payment boundary defines where and how an AI agent can make payments—specifying allowed domains, blocked contracts, permitted chains, and spending limits to prevent unauthorized transactions.

            

            

                
How does the Spending Limit Lock work?

                
Set per-transaction, daily, and weekly limits in USD, ETH, USDC, or BNB. The agent cannot exceed these limits even when instructed to do so.

            

            

                
Which blockchain networks are supported?

                
Ethereum, BSC, Polygon, Arbitrum, Solana, and custom chains. Select multiple chains when creating your payment boundary.

            

            

                
Is AgentPay Guard compatible with WebMCP?

                
Yes, generates WebMCP-compatible JSON configurations. Output can be pasted directly into WebMCP agent configuration files.

            

            

                
Can I use this for DeFi agent strategies?

                
Absolutely. Perfect for DeFi agents executing swaps, liquidity provision, or yield farming with multi-chain support and token filtering.

            

            

                
Is my data sent to any server?

                
No. 100% client-side. All processing happens in your browser. Configurations are never transmitted to any server.

            

            

                
How do I export the generated configuration?

                
Copy to clipboard with one click or download as a JSON file. Both options appear immediately after generation.

            

            

                
What payment protocols are supported?

                
WebMCP, Payment Protocol standard, and custom implementations. JSON output follows standard schema for easy integration.
