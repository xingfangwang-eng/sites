## KEYWORDS
DeFAI Security | Agent Audit | Smart Contract Risk | Autonomy Limits | Rug-pull Detection

## DESCRIPTION
AgentSanity is a heuristic security scanner designed for the emerging Agentic Economy. It provides instant sanity checks for AI Agent smart contracts, helping users assess autonomy risks, ownership vulnerabilities, and potential exit-scam patterns.

## USAGE
1. **PASTE CONTRACT**: Enter the AI Agent's smart contract address in the input field
2. **RUN SANITY CHECK**: Click 'START_SECURITY_AUDIT' to initiate the scan
3. **REVIEW THREAT LEVEL**: Analyze the Sanity Score and Risk Dashboard results

## FEATURES
- **Autonomy Limit Scanning**: Assess the balance between agent freedom and user safety
- **Smart Contract Risk Scoring**: Generate deterministic security scores (0-100%)
- **Ownership Audit**: Detect single-owner concentration and multisig configurations
- **Timelock Verification**: Check for timelock protection on critical functions
- **Upgrade Risk Detection**: Identify proxy patterns and upgradeable contracts
- **Withdrawal Limit Analysis**: Evaluate fund withdrawal guardrails
