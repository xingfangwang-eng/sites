FAQ - WebMCP Security Gateway

            

                
What is WebMCP Shield?

                
WebMCP Shield is an AI-native security gateway generator that creates code snippets to protect your website from unauthorized AI agent access and secure payment transactions.

            

            

                
How does the security gateway work?

                
The gateway implements Content Security Policy headers, agent identity verification, session isolation, and transaction signing to ensure secure agent interactions.

            

            

                
Which payment gateways are supported?

                
Currently supports Stripe, PayPal, and cryptocurrency payments with built-in security validation.

            

            

                
What access levels are available?

                
Three levels: Strict (read-only), Moderate (limited write), and Flexible (full access) for different security requirements.

            

            

                
Is this service free?

                
Yes, WebMCP Shield is completely free to use with no registration required.

            

            

                
Do I need an API key?

                
No, this is a pure frontend tool. No API key or backend connection is required.

            

            

                
How long does deployment take?

                
Deployment takes less than 5 minutes - simply copy and paste the generated code into your website.

            

            

                
Is WebMCP Shield compatible with all websites?

                
Yes, WebMCP Shield works with any HTML-based website regardless of platform or framework.
